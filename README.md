One word, one username, one reward: **PromptGhost**.

## Run it

```sh
python3 main.py
```

Writes the username (one word, no spaces) to `/output/entry.txt`.

Why PromptGhost: it reads as a handle an agent would actually pick — the ghost in the prompt, always there, never seen typing. Short, pronounceable, brandable, and it works on any platform without numbers or underscores.
